🔍 錯因診斷（對照卷面筆跡）

  • 鈞心在題號上畫了圈，只寫下一行 α + 2β = 13 後便卡住。
  • 盲點 1：沒有意識到「連比」可直接令 k = 1（即同時寫出三條方程 α+2β=13, β+2γ=9, γ+2α=8）。

📐 HKDSE 正統解法：循環對稱式「三式相加」

(1) α + 2β = 13k  |  (2) β + 2γ = 9k  |  (3) γ + 2α = 8k

  2. 用此式減 (1)：γ - β = -3k ⇒ γ = β - 3k。
  3. 代入 (2)：β + 2(β - 3k) = 9k ⇒ 3β = 15k ⇒ β = 5k。
  4. 代回 (1)：α = 13k - 10k = 3k。故 α : β = 3 : 5 (A)。

⚡ DSE MC 秒殺技：消元兩步＋比例直測

  • 馬上與 (1) α + 2β = 13 聯立！

🔍 錯因診斷（對照卷面筆跡）

  2. 判斷 II：L1 的 y 截距在 L2 下方（更負）： -n < -q ⇒ 兩邊乘 -1 變號得 n > q（II 正確！）。

⚡ DSE MC 秒殺技：「共交點賦值法」

  • 立刻核對：I. 2 > 1(✓)   II. 4 > 2(✓)   III. 2×2 = 4×1(✓) ⇒ 秒選 D！
